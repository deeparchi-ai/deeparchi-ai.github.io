开发者说明

首页保留四项服务，其中 Deep BLM 提供独立的浏览器规划工具试用，其余三项为本地概念 walkthrough，用于了解需求。它不是协议符合性演示，不提供运行中的 Agent Card、任务服务或 A2A endpoint。

现在可以读取什么

service-catalog.json 是真实的同源 JSON 目录。服务 ID 与首页一致，Deep BLM 的 availability 为 web-trial，其余为 concept-demo；所有服务的 production_ready 为 false；a2a.available 为 false，endpoint 为 null。拟议输入输出描述服务设想，不构成可调用契约。

Deep BLM 网页试用

工具入口在电脑浏览器提供完整 15 步手工编辑、校验与修订，手机提供轻量产品与咨询说明。静态资源均为本地固定版本；JSON 兼容扁平与分步结构并限制字段、表格、体积与深度。Word 兼容 .doc 为经过净化的 HTML，不是原生 .docx。

工具的本机自动保存不等于云端同步，不提供账号。Key 仅存本页内存，AI 需自备 Key 并明确同意外部处理；模型兼容性与真实生成尚未验证。公共链接抓取和网络搜索已关闭。工具不初始化首页统计；首页 demo_open 只记录获同意的工具入口兴趣，不能当作规划完成量。

未来可能如何协作

  • 发现：在服务可用且经过验证后，再定义可发现的服务信息。
  • 授权任务：先确认身份、数据权限、范围、人工复核与取消边界，再接受任务。
  • 进度与产物：再约定状态、证据、交付结构和验收；首页仅展示虚构样例。

未来实现应以 A2A 官方文档 为参考，并独立验证。现有 A2A 方向仅接受私测意向沟通，当前网站不会执行任务。

匿名事件的接入边界

只有配置已获准的 HTTPS 接收地址、启用统计、访问者主动同意且未启用 DNT/GPC 时，才允许发送枚举事件。下方设置显示本页状态；默认不发送，不回放同意前动作。配置无效时明确提示并关闭。统计接收不等于 A2A 任务接入，不代表需求已验证。

事件只允许服务/分类、界面位置、事件、版本、browser_interaction 交互来源（不能核验自然人）、is_test、随机临时会话与事件 ID，以及 A2A 样例步骤号。不包括输入文本、邮箱、完整 URL、来源页或持久标识。会话去重不等于独立人数。

自动化使用 ?internal_test=1；本地或测试模式禁用实际传输，只允许测试显式注入的 fixture transport。模拟回执不代表远端接收成功。本次接收端有累计/每日/会话/测试限额及精确 Origin 校验；并非鉴别人或机器的认证系统。到期标记不代表自动删除，平台基础日志字段与保留期待确认，详见隐私说明。
